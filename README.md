# Interaktivt historisk kort — hover v1

Denne version holder koden opdelt i:
- `index.html`: struktur
- `style.css`: designsystem og hover-styling
- `map.js`: kortets zoom og panorering
- `interactions.js`: hotspot og informationsboks

Hotspot:
- Klik åbner informationsboksen.
- Hover forstørrer markøren og viser en lille label.
- Koden er forberedt til et fritlagt billede som `assets/rabbit.png`.
- Det billede, der tidligere blev sendt, har stor sort flade og papirbaggrund omkring kaninen, så det er ikke et rent fritlagt PNG-asset endnu. Derfor er selve billed-overlayet slået fra, indtil I har en transparent PNG.

## Upload
Upload og erstat `index.html`, `style.css`, `map.js` og `interactions.js` i repositoryets rod. `assets/` kan tilføjes senere, når den endelige kanin-PNG er klar. Commit changes, vent et minut, og genindlæs siden med Cmd+Shift+R.
